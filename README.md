# deltafight
Not ready yet. Version 0.1. This is a recreation of the Deltarune fighting system that got me hard. I am a fan of Undertale and Deltarune myself, so I did this.
This contains SOUL, TP, player options to FIGHT, MAGIC, ITEM, SPARE and DEFEND. There will be some custom ITEMs as StrangeCard (25% to heal team 40HP, 25% to set TP to MAX, 25% to damage team 25HP, 25% to set TP to 0), InnocentBird (Heals 40HP) and GoodOne (Sets TP to MAX).
Plan to add random enemies each time you start... I don't know yet. Might also turn into a fangame/game.
